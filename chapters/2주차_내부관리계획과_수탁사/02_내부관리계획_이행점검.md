# 2주차-02. 내부 관리계획 이행 점검

| 구분 | 내용 |
|---|---|
| 고객사 | A사(민간) · B기관 연간 정기 점검에도 같은 방법 적용 |
| 관련 산출물 | 이행 점검표(이 챕터 9절), `./deliverables/05_증적_매핑표.md` |
| 선행 챕터 | 2주차-01. 내부 관리계획 수립과 개정 |
| 예상 학습 시간 | 3.5시간 (읽기 1.5시간 + 실습 2시간) |

---

## 1. 학습 목표

1. 내부 관리계획 이행 실태 점검 계획(대상·항목·방법·결과 처리)을 세울 수 있다.
2. 계획에 적힌 기준과 실제 운영 기록을 대조해 차이를 찾고 판정 초안을 쓸 수 있다.
3. Windows 11 도구로 업무용 PC·계정 설정 일부를 직접 확인하고 증적으로 남길 수 있다.

---

## 2. 현장 비유와 기초 개념

> 🏗️ **현장 비유**: 이행 점검은 **다이어트 계획표와 실제 식단 일기를 나란히 놓고 보는 일**이다. 계획표가 훌륭해도 일기가 비어 있으면 점수는 없다.

> 📌 **기초 개념 짚기**
> 개인정보 보호책임자는 접근 권한 관리, 접속기록 보관 및 점검, 암호화 조치 등 내부 관리계획의 이행 실태를 연 1회 이상 점검·관리해야 한다. 점검은 감사팀·보호팀·전문업체 등이 수행할 수 있지만 CPO 책임하에 수행해야 한다.
> - 근거: 안전성 기준 제4조제4항[^safe4], 안내서 p.58[^g58]

시험 지식은 "연 1회 이상 점검"이라는 문장입니다. 현장에서 컨설턴트가 그 점검을 **대신 수행**하는 경우가 많고, 이때 점검 결과서는 **고객사 CPO의 이름으로** 나갑니다. 컨설턴트는 근거와 증적을 빈틈없이 남겨야 합니다.

| 안전성 기준 제10조·제12조·제13조 | 물리적 보관, 출력·복사, 파기 | 현장 확인과 기록 확인 | [^safe] |

## 4. 컨설팅 수행 절차

```mermaid
flowchart TD
    A["점검 계획 수립<br/>(대상·항목·방법·일정·인력·후속조치)"] --> B["점검 항목표 작성<br/>(계획상 기준 열 = 내부 관리계획 문구)"]
    B --> C["증적 요청·수집"]
    C --> D["문서 대조<br/>계획 기준 ↔ 운영 기록"]
    D --> E["시스템·현장 확인<br/>(샘플 PC·계정·DB·보관 장소)"]
    E --> F{"계획과 실제가 같은가?"}
    F -->|"같음"| G["🟢 판정 초안"]
    F -->|"다름"| H["원인 분류<br/>계획이 비현실적 / 운영 누락"]
    H --> I["🟡·🔴 판정 초안 + 개선 의견"]
    G --> J["PM 검토 → CPO 보고"]
    I --> J
    J --> K["중대 사안은 대표자 보고·후속조치 추적"]
```

> 원인 분류가 중요합니다. **계획이 비현실적**이면 계획을 고치고(2주차-01로 돌아감), **운영이 누락**됐으면 운영을 고칩니다. 둘을 섞으면 개선 권고가 엉뚱해집니다.

### 단계별 설명

| 단계 | 하는 일 | 입력 자료 | 결과물 | 소요 (예시) |
|---|---|---|---|---|
| 1. 계획 | 안내서 6요소로 점검 계획서 작성 | 내부 관리계획 현행본 | 점검 계획서 | 0.5일 |
| 2. 항목표 | 계획 조항마다 "계획상 기준"을 그대로 옮김 | 내부 관리계획 | 이행 점검표 (9절) | 0.5일 |
| 3. 문서 대조 | 기록 횟수·기간·승인 확인 | 증적 | 대조 결과 | 1~2일 |
| 4. 시스템·현장 | 샘플 확인, 캡처 | 테스트 계정, 현장 출입 | 화면 캡처·사진 | 1일 |
| 5. 판정·보고 | 판정 초안, 개선 의견, 보고서 | 위 결과 | 점검 결과서 초안 | 1일 |

### Windows 11 실무 도구 팁 (샘플 PC 확인, 고객사 담당자 입회하에)

| 작업 | 도구·경로 | 방법 |
|---|---|---|
| 백신 엔진·정의 업데이트 상태 (제9조) | PowerShell | `Get-MpComputerStatus \| Select-Object AntivirusEnabled, AntivirusSignatureLastUpdated, RealTimeProtectionEnabled` → 정의 업데이트 일시가 하루 이내인지 확인 (Microsoft Defender를 쓰는 경우) |
| Windows 보안 업데이트 적용 이력 (제9조제2항) | PowerShell | `Get-HotFix \| Sort-Object InstalledOn -Descending \| Select-Object -First 5` |
| 로컬 계정 잠금 정책 (제5조제6항 관련) | `secpol.msc` → 계정 정책 → 계정 잠금 정책, 또는 명령 프롬프트 `net accounts` | 잠금 임계값 설정 확인 (도메인 PC는 그룹 정책 결과 `gpresult /r` 참고) |
| 로그온 실패 기록 | 이벤트 뷰어(`eventvwr.msc`) → Windows 로그 → 보안 → 이벤트 ID 4625 필터 | PowerShell: `Get-WinEvent -FilterHashtable @{LogName='Security'; Id=4625} -MaxEvents 10` (관리자 권한 필요) |
| 화면보호기·잠금 (업무 PC 관리) | 설정 → 개인 설정 → 잠금 화면 → 화면 보호기, 또는 그룹 정책 결과 | 개인정보처리시스템 세션 자동 차단(제6조제4항)은 **시스템 설정**에서 따로 확인 |
| 파일 공유 설정 (제6조제3항) | PowerShell `Get-SmbShare` | 불필요한 공유 폴더(Everyone 권한 등) 확인 |
| BitLocker 등 저장장치 암호화 (제7조제5항 관련) | PowerShell `manage-bde -status C:` (관리자) | 취급자 PC 저장 개인정보 보호 수단 확인 |

> ⚠️ 고객사 PC에서 명령을 실행할 때는 **사전에 고객사 승인**을 받고, 담당자가 직접 실행하게 한 뒤 화면을 캡처합니다. 컨설턴트가 설정을 바꾸지 않습니다.

### 6-2. 점검 결과 설명 멘트 (PM 확정 후, CPO 대상)

> "내부 관리계획 23개 조항 중 17개는 계획대로 운영되고 있었습니다. 차이가 있는 6개 중 4개는 운영 누락이고 2개는 계획 자체가 현실과 맞지 않았습니다. 예를 들어 접속기록 점검은 계획에 '월 1회'로 되어 있지만 실제로는 분기 1회였습니다. 여기서 선택지가 두 가지입니다. 점검 체계를 보강해 월 1회를 지키시거나, 처리 규모와 위험을 검토해 실제로 지킬 수 있는 주기로 계획을 고치시는 것입니다. 어느 쪽이든 정한 주기대로 기록이 남는 것이 핵심입니다."

## 8. 오답노트

| ❌ 신입의 실수 | ✅ 올바른 수행 | 근거 |
|---|---|---|
| 점검표의 기준 열에 고시 조문을 적고 고객사 계획 문구는 옮기지 않음 | 기준 열에는 **고객사 내부 관리계획 문구**(주기·방법·담당)를 그대로 쓰고, 고시 조문은 근거 열에 씀 | 이행 점검은 "계획대로 하고 있는가"를 본다 |
| 접속기록 점검 결과서가 "있다"는 것만 보고 양호 판정 | 계획상 주기(예: 월 1회) 대비 **실시 횟수**(예: 12회 중 4회)를 세어 판정 | 안전성 기준 제8조제2항[^safe] |
| 퇴직자 명단 없이 시스템 계정 목록만 보고 "활성 계정 이상 없음" 판정 | 인사 퇴직·전보 명단과 계정 목록, 권한 말소일을 대조 | 안전성 기준 제5조제2항[^safe] |
| 고객사 PC에서 직접 설정을 바꾸거나 파일을 복사함 | 담당자가 실행하고 컨설턴트는 캡처만. 사전 승인 필수 | 고객 시스템 변경은 컨설턴트 권한 밖 |
| 교육 결과서의 "실시"만 보고 양호 판정 | 대상자 대비 이수율, 차등 교육 여부, 미이수자 후속조치 확인 | 안전성 기준 제4조제2항, 안내서 p.55[^g55] |
| 점검 결과를 실무 담당자에게만 공유하고 끝냄 | CPO 보고, 중대 사안은 대표자 보고와 후속조치 추적까지 | 안내서 p.58[^g58] |

## 11. 실습 과제 / 퀴즈

> 정답과 해설은 [answers_and_explanations.md](../../answers_and_explanations.md)의 **「2주차-02. 내부 관리계획 이행 점검」** 절에 있습니다.

### 객관식

**Q1.** 「개인정보의 안전성 확보조치 기준 안내서」가 제시한 이행 실태 점검·관리 계획(예시)의 구성 요소가 **아닌** 것은?

① 점검 대상 및 시기
② 점검 항목 및 내용
③ 점검 결과 후속조치(개선, 보고)
④ 점검 결과에 따른 과태료 산정

**Q2.** A사 내부 관리계획에 "접속기록은 월 1회 점검한다"고 되어 있다. 최근 1년간 점검 결과서는 4회분(분기별)이다. 신입의 판정 초안으로 가장 적절한 것은?

① 고시에 주기가 정해져 있지 않으므로 🟢 양호
② 계획상 기준(월 1회) 대비 이행 4/12회로 🟡 부분 이행 또는 🔴 미흡 초안을 쓰고, 원인(계획 비현실 / 운영 누락)을 메모해 PM에게 넘긴다.
③ 분기 1회도 충분하므로 계획을 분기로 고쳐 주고 🟢 양호
④ 점검 결과서가 있으므로 판정 대상이 아니다.

**Q3.** 샘플 PC에서 백신 정의 업데이트 상태를 확인하려 한다. Windows 11에서 Microsoft Defender를 쓰는 경우 적절한 방법은?

① `Get-MpComputerStatus` 결과의 `AntivirusSignatureLastUpdated` 확인
② `ipconfig /all` 결과 확인
③ `Get-HotFix`로 백신 정의 날짜 확인
④ 작업 관리자의 CPU 사용률 확인

### 실습

**상황**: A사 이행 점검 자료가 모였다. 9절 이행 점검표를 작성하라.

**제공 자료**

```text
[A사 내부 관리계획(2026-02 개정본) 중 일부]
- 권한: 인사 발령 후 3영업일 내 변경·말소, 내역 3년 보관
- 접속기록: 월 1회 점검(다운로드 1,000건 이상 시 사유 소명)
- 교육: 연 1회, 취급자·개발자·수탁자 대상별 차등
- 수탁자: 반기 1회 서면 점검, 연 1회 고위험 수탁사 현장 점검

[수집된 사실]
- 2025.9~2026.2 퇴직자 8명 중 2명 계정이 2026-03 현재 활성 상태
- 권한 변경 이력: 2024-01부터 보관
- 접속기록 점검 결과서: 2025-03 ~ 2026-02 중 9회분, 다운로드 소명 기록 3건
- 교육: 2025-11 전 직원 동일 온라인 교육 1회, 이수율 92%
- 수탁자 점검: 2025 상반기 서면 점검 7곳, 하반기 없음, 현장 점검 없음
- 샘플 PC 4대 중 1대 백신 정의 업데이트 일시 2026-02-10 (점검일 2026-03-24)
```

**과제**

1. 9절 형식으로 항목별 판정 초안과 판정 근거를 쓰시오.
2. 각 미흡·부분 이행 항목의 원인을 "계획 비현실 / 운영 누락" 중 하나로 분류하고 이유를 쓰시오.
3. CPO 보고용 요약(5줄 이내)을 쓰시오.

**작성 양식**: 9절 이행 점검표
