## 0단계. 점검 대상 선정과 등급화

위탁자는 수탁자를 위험도로 등급화한 뒤 현장 점검, 원격 점검 등 다양한 수단을 합리적으로 골라 감독할 수 있습니다. 예시 절차는 **사전평가 → 수탁자 분류(등급화) → 체크리스트를 통한 수탁자 자체 점검 → 수탁자 이행계획서 제출 → 위탁자 현장점검 및 원격점검 → 감독 결과 도출 및 사후 조치**입니다.[^integ175][^qa]

| 수탁사 | 위탁 업무 | 처리 개인정보 (고유식별·민감 여부) | 처리 규모 (정보주체 수) | 전송 방식 | 재위탁 여부 | 인증 보유 (ISMS-P 등) | 등급 | 점검 방식 |
|---|---|---|---|---|---|---|---|---|
| | | | | | | | | |

> 등급 기준(예: 고유식별정보를 처리하거나 10만 명 이상이면 "상")은 **PM이 고객사와 합의해 정합니다.** 신입은 위 표의 사실 정보를 채웁니다.

## 1단계. 점검 항목

|---|---|---|---|---|---|---|---|---|
| A1 | 계약 문서 | 위탁 계약이 **문서**로 체결되어 있다 | 문서 | 위수탁 계약서(현행) | 🟢 서명된 현행 계약서 있음 · 🔴 없음 또는 만료 | | | |
| A2 | 계약 문서 | 계약서에 법정 포함 사항 7개(법 2개 + 시행령 5개)가 모두 있다: ① 목적 외 처리 금지 ② 기술적·관리적 보호조치 ③ 위탁업무 목적·범위 ④ 재위탁 제한 ⑤ 접근 제한 등 안전성 확보조치 ⑥ 관리 현황 점검 등 감독 ⑦ 손해배상 등 책임[^law26][^dec28] | 문서 | 위수탁 계약서 | 🟢 전부 포함 · 🟡 일부 누락 · 🔴 다수 누락 | | | |
| A3 | 계약 문서 | 위탁 종료 시 개인정보 **반환 또는 파기**와 그 확인 방법이 계약서에 있다 | 문서 | 위수탁 계약서 | 🟢 포함 · 🔴 없음 | | | |
| B1 | 목적 외 이용 금지 | 위탁받은 업무 범위를 넘어 이용하거나 제3자에게 제공하지 않는다 | 인터뷰·시스템 | 업무 매뉴얼, 데이터 반출 기록 | 🟢 범위 내 처리 확인 · 🔴 범위 밖 이용 확인 | | | |
| C1 | 재위탁 | 재위탁한 경우 위탁자의 **동의**를 받았다 | 문서 | 재위탁 동의 문서, 재수탁사 목록 | 🟢 동의 증빙 있음 · 🔴 동의 없이 재위탁 · ⚪ 재위탁 없음(확인서) | | | |
| D1 | 교육 | 위탁자가 수탁사 취급자를 교육했거나, 협의한 방식(자체 교육 등)으로 교육하고 증빙을 받았다[^integ174] | 문서 | 교육 자료, 참석자 명단·이수 현황 | 🟢 최근 1년 증빙 있음 · 🟡 일부 인원만 · 🔴 없음 | | | |
| E1 | 안전조치 | 내부 관리계획을 수립·시행하고 있다 | 문서 | 내부 관리계획과 승인 문서 | 🟢 수립·승인·시행 · 🟡 수립만 · 🔴 없음 | | | |
| E2 | 안전조치 | 처리시스템 접근 권한을 최소 범위로 부여하고, 인사이동 시 지체 없이 변경·말소한다 | 시스템 | 계정 목록, 인사 변동 명단 | 🟢 불일치 없음 · 🔴 퇴직자 계정 등 확인 | | | |
| E3 | 안전조치 | 권한 부여·변경·말소 내역을 **3년 이상** 보관한다[^safe5] | 문서·시스템 | 권한 변경 이력 | 🟢 3년분 있음 · 🟡 일부 기간 · 🔴 없음 | | | |
| E4 | 안전조치 | 계정을 취급자별로 발급하고 공유하지 않는다 | 시스템·인터뷰 | 계정 목록 | 🟢 개인별 계정 · 🔴 공용 계정 사용 | | | |
| E5 | 안전조치 | 외부에서 처리시스템에 접속할 때 안전한 인증수단(이용자가 아닌 정보주체 처리 시스템은 VPN 등 안전한 접속수단도 가능)을 쓴다[^safe6] | 시스템 | 원격접속 설정 화면 | 🟢 적용 · 🔴 ID/PW만으로 접속 | | | |
| E6 | 안전조치 | 일정 시간 업무처리를 하지 않으면 자동으로 접속이 차단된다 | 시스템 | 세션 타임아웃 설정 | 🟢 적용 · 🔴 미적용 | | | |
| E7 | 안전조치 | 인증정보·고유식별정보 등 암호화 대상을 암호화한다 | 시스템 | 암호화 적용 현황, DB 화면 | 🟢 대상 전부 적용 · 🟡 일부 · 🔴 평문 저장 | | | |
| E8 | 안전조치 | 처리시스템 접속기록을 보관(1년 이상, 해당 시 2년 이상)하고 정한 주기로 점검한다[^safe8] | 문서·시스템 | 접속기록 샘플, 점검 결과 | 🟢 보관·점검 이력 있음 · 🟡 보관만 · 🔴 없음 | | | |
| E9 | 안전조치 | 백신을 자동 업데이트하거나 일 1회 이상 업데이트한다[^safe9] | 시스템 | 백신 관리 콘솔 화면 | 🟢 최신 · 🔴 미설치·미갱신 | | | |
| E10 | 안전조치 | 개인정보가 포함된 서류·보조저장매체를 잠금장치가 있는 곳에 보관한다[^safe10] | 현장 | 보관 장소 사진 | 🟢 잠금 보관 · 🔴 개방 보관 | | | |
| E11 | 안전조치 | 출력 시 용도를 특정하고 출력 항목을 최소화한다[^safe12] | 시스템·현장 | 출력 화면, 출력물 관리 기록 | 🟢 적용 · 🔴 전체 항목 출력 | | | |
| E12 | 안전조치 | 파기할 때 고시가 정한 방법(완전파괴, 소자, 초기화·덮어쓰기 등)을 쓰고 기록을 남긴다[^safe13] | 문서·현장 | 파기 대장, 파쇄 증빙 | 🟢 방법·기록 있음 · 🔴 없음 | | | |
| F1 | 유출 대응 | 유출등을 알게 되면 위탁자에게 즉시 알리는 절차가 계약서나 내부 절차에 있다 | 문서 | 사고 대응 절차서 | 🟢 있음 · 🔴 없음 | | | |
| G1 | 종료 후 | (종료 계약) 반환 또는 파기를 완료했고, 위탁자가 그 증빙을 확보했다[^integ178] | 문서 | 파기 확인서 | 🟢 증빙 있음 · 🔴 없음 · ⚪ 종료 계약 없음 | | | |

> 💡 E 영역은 수탁자에게도 법 제29조(안전조치의무)가 준용되기 때문에 확인합니다.[^law268] 수탁사 규모·업무에 따라 행을 더하거나 빼되, 뺀 행은 ⚪ 해당 없음과 사유로 남깁니다.
