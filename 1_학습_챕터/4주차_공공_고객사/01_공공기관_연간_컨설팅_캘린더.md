# 4주차-01. 공공기관 연간 컨설팅 캘린더

| 구분 | 내용 |
|---|---|
| 고객사 | B기관(공공, 매년 고정 연간 컨설팅) |
| 관련 산출물 | B기관 연간 컨설팅 캘린더(이 챕터 4절 gantt), `./2_산출물_양식/06_보호수준평가_증빙_관리표.md` |
| 선행 챕터 | 1~3주차 전체 |
| 예상 학습 시간 | 3시간 (읽기 1.5시간 + 실습 1.5시간) |

> [!IMPORTANT]
> **🎯 이 챕터 핵심 3줄**
> 1. 공공기관은 보호수준 평가(매년), 영향평가(설계 완료 전·2개월·1년), 파일 등록(60일 이내), 연 1회 점검·교육이 1년 내내 맞물린다.
> 2. 법령상 고정 기한 규칙과 평가계획 통보 후 확정되는 일정을 구분한다. 보호수준 평가 세부 일정은 통보 전까지 자리표시다.
> 3. 겹치는 시기에는 한 번 만든 산출물을 여러 평가에 재사용하고, 유출 대응 훈련(72시간)도 고정 일정으로 넣는다(SKT 통지 지연 사례).

---

## 1. 학습 목표

1. B기관이 1년 동안 지켜야 하는 개인정보 보호 의무 일정(보호수준 평가, 영향평가, 정기 점검, 파일 등록 등)을 근거와 함께 나열할 수 있다.
2. 법령상 고정 기한과 평가계획 통보 후 확정되는 일정을 구분해 연간 캘린더(gantt)를 그릴 수 있다.
3. 일정이 겹치는 시기에 산출물을 재사용하는 방법을 제안할 수 있다.

---

## 2. 현장 비유와 기초 개념

> [!TIP]
> 🏗️ 💡 현장 비유: 공공기관 연간 컨설팅은 **학교 학사력**과 같다. 중간고사(보호수준 평가), 수행평가(영향평가), 정기 건강검진(내부 점검)이 정해진 시기에 겹쳐 오므로, 학기 초에 달력을 짜 두지 않으면 시험 전날 밤을 새운다.

> [!NOTE]
> 📌 **기초 개념 짚기**
>
> 공공기관은 민간 처리자의 의무에 더해 **개인정보 보호수준 평가**(매년), 개인정보 영향평가(대상 개인정보파일), 개인정보파일 등록(운용 시작일부터 60일 이내) 등 공공 특유의 의무가 있다. 공공시스템운영기관은 안전성 기준 제3장의 추가 조치도 해야 한다.
> - 근거: 「개인정보 보호법」 제11조의2, 제32조, 제33조[^law], 시행령 제13조의2, 제34조, 제35조[^dec], 안전성 기준 제14조~제18조[^safe]

```mermaid
flowchart LR
    B["B기관"] --> P1["민간 처리자 공통 의무<br/>(내부 관리계획·교육·수탁자 감독)"]
    B --> P2["공공 특유 의무"]
    P2 --> L["보호수준 평가<br/>(매년)"]
    P2 --> I["영향평가<br/>(대상 파일)"]
    P2 --> F["파일 등록<br/>(60일 이내)"]
    P2 --> S["공공시스템운영기관<br/>추가 조치"]
```

민간 고객사는 "인증 심사일" 하나가 큰 기준점이라면, B기관은 **여러 의무가 1년 내내 맞물려** 돌아갑니다. 신입이 연간 캘린더를 정확히 관리하면 PM의 부담이 크게 줄어듭니다.

> ✅ **2절 한 줄 정리**: 공공기관은 민간 의무에 공공 특유 의무가 더해져 1년 내내 맞물리므로, 연간 캘린더 관리가 핵심이다.

## 3. 근거 법령·기준

| 의무 | 핵심 기한·주기 | 출처 |
|---|---|---|
| ① 개인정보 보호수준 평가 | **매년**, 평가계획 통보 | [^law] [^dec] |
| ② 2026년 보호수준 평가단 위촉 | 2026.8.24. 위촉식 | [^lvl] |
| ③ 개인정보 영향평가 | 설계 완료 전, **2개월 이내**, **1년 이내** | [^law] [^dec] [^pia] |
| ④ 영향평가 예산 | **직전 연도에 예산 확보** | [^piag18] |
| ⑤ 개인정보파일 등록 | **60일 이내** | [^law] [^dec] |
| ⑥ 내부 관리계획 이행 실태 점검 | **연 1회 이상** | [^safe] |
| ⑦ 개인정보 보호 교육 | 연 1회 이상 | [^safe] [^g55] |
| ⑧ 수탁자 교육·감독 | 내부 관리계획에서 정한 주기 | [^law] |
| ⑨ 공공시스템운영기관 추가 조치 | **2027.1.1. 시행** | [^safe] |
| ⑩ 처리방침 | 등록 대상 개인정보파일 | [^law] |

**🔎 번호별 보충 설명** (근거 / 기한·주기 전문)

- ① 근거: 법 제11조의2, 영 제13조의2
  - 기한·주기: 매년. 보호위원회가 평가 전에 평가대상·기준·방법·지표를 포함한 **평가계획을 통보**
- ② 근거: 2026 평가단 위촉 보도자료
  - 기한·주기: 2026.8.24. 위촉식. 평가단은 현지실사, 결과 평정, 우수·미흡 사례 발굴 수행 예정
- ③ 근거: 법 제33조, 영 제35조·제38조, 영향평가 고시
  - 기한·주기: 대상 파일 구축·변경 시 **설계 완료 전** 수행. 영향평가서를 받은 날부터 2개월 이내 보호위원회 제출. 개선사항 이행결과는 2개월 이내, 이후 조치분은 1년 이내 제출
- ④ 근거: 수행안내서
  - 기한·주기: 영향평가 사업은 직전 연도에 예산 확보, 당해 연도에 평가기관 선정
- ⑤ 근거: 법 제32조, 영 제34조제1항
  - 기한·주기: 운용 시작일부터 60일 이내 등록 신청, 변경 시에도 같음
- ⑥ 근거: 안전성 기준 제4조제4항
  - 기한·주기: 연 1회 이상
- ⑦ 근거: 안전성 기준 제4조제2항, 안내서
  - 기한·주기: 정기 실시 (안내서: **연 1회 이상**)
- ⑧ 근거: 법 제26조제4항
  - 기한·주기: 내부 관리계획에서 정한 주기
- ⑨ 근거: 안전성 기준 제14조~제18조, 부칙
  - 기한·주기: 제15조제5호·제18조는 2027.1.1. 시행
- ⑩ 근거: 법 제30조
  - 기한·주기: 공공기관은 **등록 대상 개인정보파일**에 대해 정함. 변경 시 공개

> [!WARNING]
> ⚠️ **확인 필요**: 보호수준 평가의 자체평가 제출, 심층평가, 현지실사, 결과 통보 등 **세부 일정은 보호위원회가 매년 통보하는 평가계획**으로 확정됩니다. 이 레포의 참고자료 폴더에는 2026년 평가단 위촉일(8.24.) 외의 세부 일정이 없으므로, 아래 캘린더의 보호수준 평가 구간은 평가계획 수령 후 바꿔 넣는 자리표시입니다.

> ✅ **3절 한 줄 정리**: 보호수준 평가는 매년(평가계획 통보), 영향평가는 설계 완료 전·2개월·1년, 파일 등록은 60일, 점검·교육은 연 1회 이상이고, 공공시스템 조항 일부는 2027.1.1. 시행이다.

### 4-3. 산출물 재사용 지도

| 한 번 만든 산출물 | 다시 쓰이는 곳 |
|---|---|
| ① 내부 관리계획 이행 점검 결과 (2주차-02) | 보호수준 평가, 영향평가 |
| ② 수탁사 점검 결과·이행 확인 (2주차-04·05) | 보호수준 평가, 영향평가 |
| ③ 처리방침 진단 (1주차-03) | 보호수준 평가, 영향평가 |
| ④ 개인정보 흐름표·흐름도 (4주차-05) | 영향평가, 파일 등록 |

**🔎 번호별 보충 설명** (다시 쓰이는 곳 전문)

- ① 보호수준 평가 안전조치 관련 증빙 후보, 영향평가 대상기관 관리체계 평가(별표 5 영역 I·II)
- ② 보호수준 평가 심층평가 "위·수탁의 적절성 및 사후관리" 증빙 후보, 영향평가 "위탁" 분야
- ③ 보호수준 평가 "처리방침 및 열람·정정·삭제·처리정지 등", 영향평가 "개인정보 처리방침" 분야
- ④ 영향평가 산출물, 개인정보파일 등록사항 확인

> [!NOTE]
> 보호수준 평가 지표의 세부 증빙 요구는 평가계획으로 확인합니다. 위 표의 "증빙 후보"는 평가 항목 이름을 기준으로 한 연결 후보입니다.

| 단계 | 🙋 신입 담당 | 🧑‍💼 PM·선임 담당 |

| 연간 계획 | 의무 목록·기한 정리, gantt 초안 | 우선순위·투입 인력 계획 |

**🔎 번호별 보충 설명** (단계별 전체 업무와 🏢 B기관 담당)

- 연간 계획
  - 🙋 신입: 의무 목록·기한 정리, gantt 초안
  - 🧑‍💼 PM·선임: 우선순위·투입 인력 계획
  - 🏢 B기관: CPO 승인, 부서별 담당 지정
- 일정 관리
  - 🙋 신입: 월간 현황 갱신, 기한 알림
  - 🧑‍💼 PM·선임: 일정 충돌 조정
  - 🏢 B기관: 내부 일정 공유
- 평가계획 반영
  - 🙋 신입: 평가계획 수령 후 지표·일정 정리

  - ❌ 작년 보호수준 평가 일정을 그대로 올해 캘린더에 "확정"으로 넣음

  - ❌ 영향평가를 시스템 개발이 끝난 뒤로 일정에 넣음
  - ✅ **설계 완료 전** 수행하도록 사업 일정과 맞춤
  - 근거: 영향평가 고시 제9조의2[^pia]
- ③
  - ❌ 영향평가 예산을 당해 연도에 확보하면 된다고 안내
  - ✅ 직전 연도 예산 확보 → 당해 연도 평가기관 선정 흐름을 안내
  - 근거: 수행안내서 p.18[^piag18]

  - ✅ 운용 시작일부터 60일 이내 등록 신청
  - 근거: 영 제34조제1항[^dec]

  - ❌ 영향평가서 제출 후 개선사항 이행 관리를 캘린더에서 뺌

  - 근거: 영향평가 고시 제12조[^pia]

## 9. 고객사 점검용 체크리스트: 연간 관리 체계

각 항목: **점검 항목** → 확인 방법 / 요청 증적 → 판정 기준

### ① 전년도·영향평가 (No 1~3)

- [ ] **No 1. 전년도 개선권고**: 전년도 보호수준 평가 결과·개선권고와 조치 결과가 관리되고 있다
  - 확인 방법: 문서 / 요청 증적: 결과 공문, 조치 결과
  - 판정 기준: 🟢 조치·회신 완료 · 🟡 진행 중 · 🔴 미조치 · ⚪ 개선권고 없음
- [ ] **No 2. 영향평가 대상·예산**: 영향평가 대상 사업이 사업계획 단계에서 식별되고 예산이 확보되었다
  - 확인 방법: 문서 / 요청 증적: 사업계획서, 예산
  - 판정 기준: 🟢 식별·예산 · 🟡 식별만 · 🔴 미식별 · ⚪ 대상 사업 없음
- [ ] **No 3. 영향평가 이행 일정**: 영향평가 개선사항 이행 일정(2개월·1년)이 관리된다
  - 확인 방법: 문서 / 요청 증적: 이행확인서, 일정표
  - 판정 기준: 🟢 관리 · 🔴 미관리 · ⚪ 해당 없음

- [ ] **No 4. 파일 등록 기한**: 개인정보파일이 운용 시작 60일 이내에 등록·변경된다
  - 확인 방법: 문서·시스템 / 요청 증적: 파일 등록 현황, 운용 시작일
  - 판정 기준: 🟢 기한 내 · 🔴 지연·미등록
- [ ] **No 5. 정기 일정**: 내부 관리계획 이행 점검·교육·수탁자 점검이 연간 일정에 있다
  - 확인 방법: 문서 / 요청 증적: 연간 계획
  - 판정 기준: 🟢 모두 · 🟡 일부 · 🔴 없음

### ③ 시행 예정·유출 대응 (No 6~7)

- [ ] **No 6. 공공시스템 대응**: 공공시스템운영기관 해당 여부와 2027.1.1. 시행 조항 대응 계획이 있다
  - 확인 방법: 문서 / 요청 증적: 대응 계획
  - 판정 기준: 🟢 있음 · 🔴 없음 · ⚪ 비해당
- [ ] **No 7. 유출 대응 훈련**: 유출 대응 절차 점검·훈련이 연간 일정에 있다
  - 확인 방법: 문서 / 요청 증적: 훈련 계획·결과
  - 판정 기준: 🟢 계획·결과 · 🟡 계획만 · 🔴 없음
